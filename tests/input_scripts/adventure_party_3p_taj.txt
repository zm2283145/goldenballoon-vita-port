# Adventure Party Taj vehicle transform (AP-11) -- THREE players.
#
# Admission prologue is byte-identical to adventure_party_3p_admit.txt (routes to
# the central hub with a 3-seat session). Then a NON-HOST (seat 1 / player two)
# summons Taj by driving into him (MDKR_AP_SEAT_ROUTE="1=-197,193", his hub
# position), and the HOST (player one) navigates Taj's menu to change the whole
# party's vehicle: CHANGE VEHICLE -> HOVERCRAFT. taj_menu_loop reads
# input_pressed(PLAYER_ONE), so the menu is host-owned regardless of who summoned.
# After the transform the host backs out of the reopened menu (B) so Taj teleports
# away and the shared dialogue is released (R10).
